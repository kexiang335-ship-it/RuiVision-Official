# RuiVision 品牌官网

RuiVision 品牌官网页：汇聚电商创作工作台、AI 生成 API 中转站、中医研习、校园生活与 GEO 分析工具，橙白一脉。

- 纯静态单页 HTML + CSS + 原生 JS，无构建依赖
- GitHub Pages 自动部署（`.github/workflows/pages.yml`）
- 商标素材位于 `assets/`

访问地址：`https://kexiang335-ship-it.github.io/RuiVision-Official/`
